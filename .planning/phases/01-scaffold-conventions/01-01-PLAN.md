scripts/lib/fixtures.mjs
- `repoRoot(): string` — absolute path of the repository root, resolved from `import.meta.url`.
- `withFixture(files: Record<string, string>, fn: (dir: string) => Promise<void>): Promise<void>`
  — creates a directory under `os.tmpdir()`, writes each key as a relative path with its
  string contents (creating parent directories), awaits `fn(dir)`, removes the directory in
  a `finally`.
- `runCheck(scriptRelPath: string, opts?: { cwd?: string, args?: string[], env?: Record<string,string> }): Promise<{ code: number, stdout: string, stderr: string }>`
  — spawns `process.execPath` with the repo-root-resolved script, no shell, `cwd` defaulting
  to `repoRoot()`, environment inherited and extended.
- `runCommand(command: string, args: string[], opts?): Promise<{ code: number, stdout: string, stderr: string }>`
  — same shape but `shell: true`, for `npx`/`next` binaries on Windows.

scripts/lib/harness.mjs
- `MOBILE_PROFILE` — frozen object `{ viewport: { width: 390, height: 844 }, deviceScaleFactor: 3, isMobile: true, hasTouch: true }`.
- `launch(): Promise<Browser>` — `chromium.launch({ headless: true })`, no GPU args.
- `openMobilePage(browser): Promise<{ context, page }>` — `browser.newContext(MOBILE_PROFILE)`
  then `newPage()`, with console-error and pageerror collectors pushed onto `page.__captureErrors`.
