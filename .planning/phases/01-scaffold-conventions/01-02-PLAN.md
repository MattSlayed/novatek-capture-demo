<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → Vercel edge (`cpt1`) | Every response to an unauthenticated phone crosses here; `vercel.json` is the only place policy is declared |
| browser → a future service worker → `/api/` | A worker that intercepts `/api/` would sit between the client and every enforced claim |
| repository source → build pipeline | Config that could silently disable a check crosses here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-01 | Denial of service (self-inflicted) | `vercel.json` `/(.*)` `Permissions-Policy` | mitigate | `check-headers.mjs` asserts the exact string `camera=(self), microphone=(self)` and pushes a named problem if `camera=()` or `microphone=()` appears anywhere in the file. |
| T-1-05 | Spoofing / Tampering | `vercel.json` `/(.*)` frame and transport controls | mitigate | `X-Frame-Options: SAMEORIGIN`, `Strict-Transport-Security: max-age=31536000; includeSubDomains`, `X-Content-Type-Options: nosniff` and `Referrer-Policy: strict-origin-when-cross-origin` asserted by exact string. |
| T-1-08 | Tampering | a future `public/sw.js` intercepting `/api/` | mitigate | `check-sw.mjs`: absent → no `serviceWorker.register(` anywhere under `app/`, `components/`, `lib/`; present → `node --check` plus the never-handle-`/api/` guard, with `respondWith` forbidden before the guard's return. |
| T-1-02 | Repudiation | production build with an unresolved build id | mitigate | `check-structure.test.mjs` runs `next build` with all three variables deleted and asserts a non-zero exit naming `CAPTURE_BUILD_ID` (D-03). |
| T-1-04 | Tampering | a check that can be skipped | mitigate | Neither `check-sw.mjs` branch skips or warns; `--build-output` is additive, never a substitute for the source assertions; no environment variable or flag suppresses any assertion (D-20). |
| T-1-10 | Elevation of privilege | Routing Middleware | mitigate | `check-structure.mjs` asserts no `proxy.ts`/`middleware.ts` exists at the root, in `app/` or in `src/` (AD-2, AD-15). |
</threat_model>
