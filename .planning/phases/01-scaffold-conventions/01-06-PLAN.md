Write `scripts/check-contrast.pairs.json` as an array of objects
`{ id, ink, ground, kind, note }` where `kind` is `"text"` or `"non-text"`. Its six entries are
01-UI-SPEC.md §Phase 1 ink-on-ground contrast-pairs manifest, in order:
`--viewer-ink-dim` on `--navy-deep` (text, the ribbon sentence);
`--viewer-ink` on `--navy-deep` (text — the ribbon `<strong>`, both `<h1>`s, the Limits body
and the English-only sentence);
`--cobalt-glow-ink` on `--navy-deep` (text, the ribbon link);
`--cobalt-glow` on `--navy-deep` (non-text, the ribbon dot);
`--control-border` on `--navy-deep` (non-text, the ribbon link's underline cue);
`--viewer-border` on `--navy-deep` (non-text, the ribbon's bottom border — the one exempted
pair). No panel-ground pairs are listed: no panel renders in Phase 1.

Write `scripts/check-contrast.mjs` with the banner and `problems`/`process.exit(1)` shape of
`../ipv-demo/scripts/check-model.mjs`. It:

1. Reads `app/styles/tokens.inherited.css` then `app/styles/tokens.capture.css`, parsing every
   `--name: value;` declaration at `:root` into one map with the later file winning, so the
   resolved value is what the cascade actually produces.
2. Resolves each pair's ink and ground: follow a single level of `var(--other)` indirection;
   accept `#rgb`, `#rrggbb` and `rgba(r, g, b, a)`. Composite an `rgba()` ink over its pair's
   ground before computing — `1 − a` of the ground plus `a` of the ink per channel, rounded to
   the nearest integer. State in the header that alpha compositing is engineering practice and
   is not specified by W3C (RESEARCH.md §Phase Requirements), and that it is what makes the
   inherited `--viewer-border` (`rgba(96, 165, 250, 0.16)`) resolve to `#193455` over
   `--navy-deep`, the value the exemption register was measured against.
3. Computes relative luminance and the contrast ratio verbatim from
   `w3.org/WAI/WCAG22/Techniques/general/G18`: sRGB channel normalised to 0–1, linearised as
   `c/12.92` when `c <= 0.03928` else `((c+0.055)/1.055) ** 2.4`, luminance
   `0.2126R + 0.7152G + 0.0722B`, ratio `(Llighter + 0.05) / (Ldarker + 0.05)`.
4. Applies the floors: 7:1 for `kind: "text"`, 3:1 for `kind: "non-text"` (D-21).
5. For any pair below its floor, reads `docs/design/decorative-exemptions.json` and passes the
   pair only if an entry names the same ink and ground AND its `measured_ratio` equals the
   computed ratio rounded to two decimal places. A below-floor pair with no entry, or with an
   entry whose measured ratio disagrees with the computation, is a problem. The register is the
   only source of exceptions; no flag, environment variable or inline comment can add one.
6. Prints every pair with its computed ratio, its floor and its verdict, then exits 1 if any
   problem was recorded. Never records a warning in place of a problem.

Write `scripts/check-contrast.test.mjs` (`node:test`) using `withFixture`/`runCheck`. Cover:
the real repository exits 0 and its printed ratios round to 7.98, 14.36, 8.62, 6.59, 4.07 and
1.33 respectively; a fixture whose capture layer sets `--viewer-ink-dim` to a value computing
below 7:1 exits non-zero; a fixture that adds a text pair with no exemption entry and a
below-floor ratio exits non-zero; a fixture whose exemption register omits the
`--viewer-border` entry exits non-zero; a fixture whose exemption entry carries a
`measured_ratio` that disagrees with the computed value exits non-zero; and a unit case
asserting the ratio of `#ffffff` on `#000000` is 21 and of a colour against itself is 1.

Write `scripts/check-wcag.mjs` following the import/launch/open shape of
`../ipv-demo/scripts/check-splat.mjs` lines 12-15 and 27-28, with the same banner and
`problems`/`process.exit(1)` contract as the other checks.

Startup guard, before anything else: import `axe-core` (bundled by `@axe-core/playwright`
4.13.0) and assert `axe.getRules(["wcag22aa"]).length >= 1`, exiting non-zero with a named
problem if it is not. This is RESEARCH.md Open Question 1's resolution: the `wcag22aa` tag
exists and carries exactly one rule, `target-size`; there is no `wcag22a` tag. The guard means
an axe upgrade that renames or drops the tag fails the check rather than silently narrowing it.

Default invocation: run `next build` then `next start` on a fixed port (use 4311), each spawned
with `shell: true` so the `next` binary resolves on Windows, with `CAPTURE_BUILD_ID` passed
through from the parent environment or derived from `git rev-parse --short HEAD` so
`next.config.ts` does not throw (D-03). Poll `http://127.0.0.1:4311/` until it answers or a
60-second budget expires, then `launch()` and `openMobilePage(browser)` from
`@/scripts/lib/harness.mjs` — the pinned 390 × 844, `deviceScaleFactor` 3, `isMobile`,
`hasTouch` profile (D-21). Always tear the server down in a `finally`: on `win32` kill the
process tree with `taskkill /pid <pid> /T /F`, otherwise `process.kill`.

For each of `/` and `/?s=limits`:
- Run `AxeBuilder({ page }).withTags(["wcag2a", "wcag2aa", "wcag21a", "wcag21aa", "wcag22aa"])`
  and push one problem per violation, naming the rule id, the impact and the first failing
  node's target. `wcag22a` is deliberately omitted — the tag does not exist.
- Assert the ribbon contract (REQ-FR-48, 01-UI-SPEC.md §Ribbon Contract's Never list), each as
  its own named problem: exactly one `section[aria-label="Preview disclosure"]` exists; it does
  not carry `aria-hidden`; its computed `position` is `static`; its computed `max-height` is
  `none`; it contains an anchor whose accessible name is `Read the full preview limits` with a
  bounding box at least 44 px high; and it contains no `button`, no `input[type=button]`, and
  no element whose accessible name or `aria-label` matches dismiss, close or hide.
- Collect `page.__captureErrors`, filter the known-noise patterns the sibling filters at
  `check-splat.mjs` lines 65-69, and report any remainder as problems.

`--self-test` invocation: skip the build and the server entirely; run the startup tag guard,
then `openMobilePage`, `page.setContent` with a deliberately inaccessible inline document (an
image with no alt text inside a document with no lang attribute), run the same `withTags` scan,
and exit non-zero unless at least one violation is reported. This proves the harness launches,
the axe wiring reports violations, and the tag set is live — in about three seconds, with no
server. `verify.mjs` runs `--self-test` immediately before the full scan.

This check is not run inside Vercel's build container: D-22 routes it through GitHub Actions,
and `verify.mjs` excludes this step when the platform's own `VERCEL` system variable is `1`.
Do not add a developer-facing skip flag; `--self-test` is a narrower, additional mode, never a
substitute for the full scan.
