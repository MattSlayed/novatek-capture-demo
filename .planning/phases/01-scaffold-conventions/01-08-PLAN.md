  <action>
Write `scripts/check-deployment.mjs` with the banner and `problems`/`process.exit(1)` shape of
`../ipv-demo/scripts/check-model.mjs`. It takes a required `--url` argument, refuses to run
without one, performs a single `fetch` with redirects followed, and asserts:

- The final status is 200 and the final URL's host is the same host that was requested. A
  redirect to `vercel.com` or a `_vercel/sso` path means Deployment Protection is still on;
  report that as a named problem with the dashboard path to turn it off, since that is exactly
  the D-24 setting this probe exists to confirm.
- The response headers carry, case-insensitively on the header name and exactly on the value:
  `permissions-policy: camera=(self), microphone=(self)`;
  `x-frame-options: SAMEORIGIN`;
  `x-content-type-options: nosniff`;
  `referrer-policy: strict-origin-when-cross-origin`;
  and a `strict-transport-security` value containing `max-age=31536000`. These are the same
  values `scripts/check-headers.mjs` asserts in source; this probe asserts them on the wire,
  which is the only place the platform's own behaviour is visible.
- The response body contains `aria-label="Preview disclosure"` and contains the string
  `Designed preview.` — the ribbon rendered before anything else. Note in the header comment
  that `scripts/` is outside the claims audit's and the governed check's `ROOTS`
  (`app`, `components`, `lib`), so this one literal here is not a second definition of a
  governed sentence; it is a wire assertion, and it is the only place in the repository outside
  `lib/copy/governed.ts` where any part of a governed sentence appears.
- The body contains no `type="button"` inside the ribbon section and no `aria-label` matching
  dismiss, close or hide — the served HTML carries no dismissal control (REQ-FR-48).

Print each assertion with its verdict and the final URL, then exit 1 if any problem was
recorded. This script is deliberately not a `verify` step: it needs a live deployment, and
D-20's gate is build-time only. Say so in the banner.
