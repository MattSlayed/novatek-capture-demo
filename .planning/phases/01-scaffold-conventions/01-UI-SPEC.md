## Typography

Absolute role split, locked by DESIGN.md §Typography, constraints.md C-7, CONTEXT.md D-15: each family carries exactly **one** weight — Syne 600 (titles), DM Sans 400 (prose), JetBrains Mono 500 (every label, uppercase, positive tracking). `<strong>` inside a governed sentence is weight 500, never 700. **13px floor everywhere**; `font-variant-numeric: tabular-nums` on every figure.

**Note on the generic "2 weights max" guideline:** this locked system does not follow the generic template pattern of one family with two weights. It uses three type families, each restricted to exactly one weight — a stricter rule in that no single family ever mixes weights, but it produces three distinct numeric weight values (600 / 400 / 500) across the type system as a whole. This is a locked upstream decision (CONTEXT.md D-15, DESIGN.md §Typography), not a Phase 1 discretionary choice, and should not be flagged for revision toward a two-weight system.

The eight governed sentences below are quoted verbatim and are never rewritten; PRD §3 glossary vocabulary is used verbatim (artisan, account, session, gate, work order, asset, capture, verification, observation, proposal, decision, referral, queue, reconciliation, conflict, governed sentence). Never write "simulation" in any form; no performance, cost or time-saving figures; never "reduce headcount"; never "records never cross the border"; no exclamation marks in any copy; no praise, celebration or encouragement copy; never imply the artisan is measured, ranked, replaced or deskilled. ### The Eight Governed Sentences (verbatim, `lib/copy/governed.ts`)

Key order on the Limits surface: `preview`, `authoredVerification`, `authoredProposals`, `noRedaction`, `memoryStore`, `noOfflineInference`, `pendingReconciliation`, `mediaOnDevice`. Each renders at `prose` (16px DM Sans 400, `--viewer-ink`) with its load-bearing clause wrapped in `<strong>` at weight 500 (never 700), separated by `--space-16`, no cards or panels between them in Phase 1.

1. **`preview`** — "**Designed preview.** Capture is specified, not yet built. The plant, the people and every record here are synthetic."
2. **`authoredVerification`** — "Matched to record — **authored for this preview. No model ran.** The match is drawn from the asset record, not from your photograph."
3. **`authoredProposals`** — "**Authored observations — no model observed this photograph.** Each is drawn from the asset's own history so the accept/reject gate can be shown working."
4. **`noRedaction`** — "**No redaction runs in this preview.** Faces, name boards and screens are not blurred. Photograph the plant, not people."
5. **`memoryStore`** — "The server keeps this **in memory only**, for a few hours at most, and discards it on cold start. There is no database behind this preview."
6. **`noOfflineInference`** — "Without signal, **nothing is verified or observed on this phone.** The capture is queued as a draft; the server does that work when you reconnect."
7. **`pendingReconciliation`** — "Decided on this phone at {time} — **pending reconciliation.** It binds only after the server confirms the order is still yours."
8. **`mediaOnDevice`** — "The full photograph stays on this phone; a small preview and a fingerprint leave it. **The recording never leaves this phone; only its fingerprint and length do.**"

Source: EXPERIENCE.md §The Honesty Surface; constraints.md C-30. Every sentence renders in full — never suppressed, softened, paraphrased, or reduced to a chip.

### Voice Rules Every String Obeys

(EXPERIENCE.md §Voice and Tone; CONTEXT.md D-19)

- Say the mechanism, not the mood.
- Name the actor.
- Every refusal carries a next act.
- Never claim more or less than is true.
- The artisan's own words are theirs.
- No exclamation marks, celebration, encouragement, streaks or praise.
- Never a euphemism for a limitation.
- Passes the claims register (`scripts/claims-audit.mjs`).

Every non-seed sentence in this document carries `[written here]`. Only two exist in Phase 1: the platform-413 sentence and the English-only limitation.

### Surface 1 — The labelled shell (`/`, no `s` query parameter)

**Structure**, top to bottom:
1. The ribbon (see `## Ribbon Contract` below), rendered by `app/layout.tsx` above `{children}`.
2. `<main aria-labelledby="screen-title">` containing one `<h1 id="screen-title" class="screen-title">NOVATEK Capture</h1>` and nothing else.

No header bar, no navigation, no other content. The header (account name, back, connectivity, queue count) is Phase 4.

**Focal point:** the eye lands on the ribbon first — it is first in document flow and its `<strong>` "Designed preview." is the only `--viewer-ink` (brightest) text in the band — then the `<h1>`.

**Reading order:** DOM order = ribbon landmark → ribbon link → `<main>` → `<h1>`. Matches visual order exactly (no CSS reordering).

### Surface 2 — The minimal Limits surface (`/?s=limits`)

**Structure**, top to bottom:
1. The ribbon (identical to Surface 1 — it renders on every screen by construction via `app/layout.tsx`).
2. `<main aria-labelledby="screen-title">` containing:

- **`position: static`** in document flow — never fixed, never sticky

- `text-decoration: none`

## Accessibility Floor

Locked by EXPERIENCE.md §Accessibility Floor, CONTEXT.md D-21, REQUIREMENTS.md REQ-NFR-5 / REQ-NFR-9. The build gates on:

- WCAG 2.2 Level AA in full, plus SC 1.4.6 (7:1 text) and SC 2.5.5 (44×44 targets).
- CI runs axe (via `@axe-core/playwright` on the Playwright 1.62.1 harness) against the production build on `/` and `/?s=limits` at a 390×844 mobile viewport, and fails on any A or AA violation.
- At 200% text: everything reflows; nothing hides or shortens; the ribbon grows to 309px (measured, not estimated).
- Operable at 320 CSS px with no two-dimensional scrolling.
- State is never conveyed by hue alone (not exercised by Phase 1's single interactive element, but binding on every later phase built against this contract).
- The ribbon is a labelled landmark (`aria-label="Preview disclosure"`) with static text and one named link — never `aria-hidden`, never announced as a region on screen change.
