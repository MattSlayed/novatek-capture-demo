    `elapsedAt(anchor, nowMono)` returning `anchor.elapsedS` plus the whole seconds elapsed
    since the anchor, floored and never negative. State in its comment that the figure is
    recomputed rather than accumulated, because Chrome throttles hidden-page timers to once a
    second and, after five minutes hidden, to once a minute — an accumulating counter would
    under-report by minutes, and this surface may not state a wrong number about a
    server-derived fact. State also that the delta is measured with a monotonic reading, so a
    device clock correction mid-segment cannot make the display jump for a reason unrelated to
    the record.

    uncapped, and a comment recording that a base-60 regrouping of an integer second count is
    lossless and reversible, so it is a rendering and not a claim. Export
    `formatInstant(iso)` returning both halves of the UI-SPEC's instant rule: the machine value
    is the server's own ISO string returned byte-unmodified, and the human value is
    `YYYY-MM-DD HH:MM:SS` in the device's own zone, one format always and never conditional on
    whether two instants share a calendar day.

    Export `clockState(clock)` returning the three states Decision 3 names — no segments, a
    segment with `closed_at === null`, and segments with none running — under names a component

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| the URL query string → the client's validation rules | `s` and `id` arrive from a link anyone can craft and are validated here before they reach a fetch. |
| the server's record → the rendered figure | Every instant and every duration on screen is derived here from a server field, never composed at a call site. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | `parseSurface`, `parseId` | mitigate | `s` is matched against a four-member closed allowlist before it can select anything; `id` is matched against an anchored `^wo-[0-9]{4}$`. Neither value is ever returned for rendering — `parseId`'s own comment states it is a fetch path segment only. React escaping is not relied on: the value never reaches markup. |
| T-04-05 | Tampering | `elapsedAt` | mitigate | The displayed figure is arithmetic over a server field and is never sent anywhere. No route accepts a duration and `POST /api/hours` returns 405 (proven in Phase 3), so a client-derived hour figure cannot enter the record. |
| T-04-06 | Integrity | `elapsedAt`, `anchorFrom` | mitigate | Recompute-from-anchor rather than accumulate, so a throttled or frozen timer makes the display update less often but never wrong; the monotonic reading is a parameter, so a device clock correction cannot move the figure. |
| T-04-07 | Tampering | this plan's commit | mitigate | Four new files, none of them the `[SECURITY]`-blocked pair. The executor commits only the files named in `files_modified`. |
| T-04-SC | Tampering | npm installs | mitigate | Zero packages; `node:test` and the platform APIs are the whole toolchain. `check-named-packages.mjs` is the standing gate. |
</threat_model>
