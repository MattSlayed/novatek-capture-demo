Turn the UI-SPEC's primitive-ownership contract into a build rule, prove the rule fails on
each violation class, and wire it into the one gate.

than re-declaring sizes, contrast or state marks locally, in the shape of the Phase 1
`check-governed` and duplicate-literal checks. Every screen plan in this phase lands after this
one, so each of them is gated by it as it is written. The recorded risk stands: a contract
written against a single consumer can encode the wrong invariant, and Phase 5 may generalise
it — which is expected, not a failure of this check.

accounting that asserts the list.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a design contract → an enforced invariant | Until a sweep asserts it, a primitive's ownership is a review note. After it, a violation cannot ship. |
| source text → the sweep's regexes | The sweep reads text, not an AST. Its blind spots are stated in its own header rather than discovered by a later reader. |
| the component tree → browser storage | A16 is the boundary: no `app/` or `components/` file touches storage, so every persisted client fact has one home under `lib/client/`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Information Disclosure | A16 | mitigate | Storage APIs and module-scope mutable state are pushed out of `app/` and `components/`, so cached server state cannot survive a persona switch in a second, unpurged location. |
| T-04-13 | Information Disclosure | A4, A9, A13, A14 | mitigate | A mark's geometry has one owner and a below-floor colour cannot be introduced locally, so no state can drift into being carried by hue alone. |
| T-04-15 | Denial of Service | A5, A6 | accept | The strongest form of the one-pinned-element rule is that Phase 4 has none. A fixed element that overlays a governed sentence is a disclosure failure rather than an availability one; the sweep's zero-times assertion is what makes it impossible to add by accident. |
