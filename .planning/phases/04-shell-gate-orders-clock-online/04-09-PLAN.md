<objective>
Build order detail and the clock: the screen where an artisan sees the order they opened, starts
and ends a segment on a single tap, and watches the accruing figure tick.

Purpose: this is the surface ROADMAP SC-1 and SC-3 are tested on. The clock is the one place in
Phase 4 where a client-rendered number stands for a server-derived fact, so the derivation is
disclosed in words, the figure is recomputed from a re-anchored server value rather than
accumulated, and nothing on the screen moves except that one text node.

Output: the clock component and its module, the order-detail surface and its module. Neither is
reachable yet; plan 04-11's switcher renders the surface.

This plan depends on 04-08 because the clock's refusal renders `components/conflict/ConflictCard.tsx`,
which 04-08 creates. The dependency is declared rather than left to wave order: without it the two
plans are parallel-eligible and this plan's own `tsc --noEmit` would fail on an unresolved import.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| the client's tick → the record | The displayed figure is arithmetic. Nothing sends it anywhere, and no route would accept it. |
| a crafted `?id=` → the order read | The id reaches a fetch path segment only. The server decides ownership and existence byte-identically before any body is parsed. |
| the server's refusal → the artisan | Either the conflict table's sentence or the envelope's `detail`, rendered as sent. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05 | Tampering | the elapsed figure | mitigate | Structurally impossible to enter the record: no route accepts a duration, `POST /api/hours` is 405, and the figure is never sent. The clock writes carry only a `client_id`. |
| T-04-06 | Integrity | the tick | mitigate | Recompute from a re-anchored server value, never accumulate; re-anchor on returning to a visible tab; measure the delta monotonically. A throttled timer makes the display update less often, never wrong. The derivation line names both actors and the mechanism and is true under either implementation. |
| T-04-01 | Tampering | the order id | mitigate | Never interpolated into markup, a URL or a header; used only as a fetch path segment. A refused read routes to the order list with the conflict table's own sentence. |
| T-04-12 | Repudiation | the clock control | mitigate | The 90 ms two-property press change is the NFR-4 confirmation and falls outside the region a gloved thumb occludes. The label swap's later arrival is recorded as a deliberate phase-bounded gap rather than hidden by a spinner. |
| T-04-21 | Denial of Service | the interval | accept | One `setInterval` at 1 Hz per mounted clock, cleared on unmount, updating a single text node. Accepted: the alternative — polling the server once a second for a figure that is arithmetic — is 60 requests a minute per artisan against a memory store and does not solve backgrounding. |
| T-04-07 | Tampering | this plan's commit | mitigate | Four new files, none of them the `[SECURITY]`-blocked pair. |
| T-04-SC | Tampering | npm installs | mitigate | Zero packages; `setInterval`, `performance.now()` and `visibilitychange` are platform APIs. |
</threat_model>
