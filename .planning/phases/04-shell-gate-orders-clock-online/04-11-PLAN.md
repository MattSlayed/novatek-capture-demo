<objective>
Wire the four surfaces onto the one route: convert the screen switcher to a Client Component
behind the existing `<Suspense>` boundary, add the header, retire the Phase 1 shell surface, and
update the two shipped files that hard-code it.

Purpose: this is the one structural change of the phase, and it is not a stylistic choice. A
Server Component's `searchParams` prop does not update on `history.pushState` — measured directly
against this repository, frozen at its first-render value across every push, replace and pop, with
zero server round trips. Only a Client Component's `useSearchParams()` tracks it. The build
enforces the other half: that hook outside a `<Suspense>` boundary is a hard `next build` error
under this project's `cacheComponents: true`, so the Suspense requirement is a build gate rather
than a review note.

Output: the switcher, the header, the retired shell and its two dependent fixtures, and one full
green gate run.
</objective>

    — the gate is not an `s` value, it is what any surface shows when there is no session — and

    `useSearchParams()` tracks and this component handles identically — the app adds no `popstate`
    listener and no gesture interceptor.

    call from their own `await` continuations; the handler stores the code and the sentence and
    calls `replaceWith("orders")`, so the URL never claims a screen the app is not on. Clear it in
    the `await` continuation of the screen-resolution effect whenever the current surface is not
    the order list, so the card never outlives the arrival it belongs to.

    derived `screenKey` **and** on the resolved-session state, so it runs once the surface's heading
    exists and re-runs on an id-only transition. Record the two measurements behind that key: an
    effect keyed on `s` alone does not re-run on `order(A) → order(B)`, which would leave focus on

    a focus rule and no scroll-restoration rule, and `focus({ preventScroll: true })` would leave
    the heading focused but off screen. The effect contains no `setState`.

    Use no `next/link`, no `useRouter`, no `router.push`, no `useParams`, no `export const instant`,
