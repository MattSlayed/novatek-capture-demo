# NOVATEK Capture — designed preview

A phone-first preview of the **Capture** surface described on

tokens, same synthetic plant, same claims discipline.

**Status: repository seeded; nothing built yet.** The seed specification is
[`docs/CAPTURE-PLAN-SEED.md`](docs/CAPTURE-PLAN-SEED.md). The build runs through BMAD
(`/bmad:master` → brief → PRD → UX spec → architecture, into `docs/planning-artifacts/`) and
then GSD (`/gsd-ingest-docs` → `.planning/` → plan / execute / verify per phase).

What this preview will make real, and what it will label as authored, is stated in the seed's
"What is real vs. labelled" table. The one sentence that governs everything here is borrowed
from `ipv-demo/HANDOVER.md`: *the demo must be real where it claims to be real.*
